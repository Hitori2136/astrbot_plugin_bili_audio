# astrbot_plugin_bili_audio

B 站音频提取插件：发送 `/提取音频 BV号`，插件会提取该视频的音频，发送可点击的 QQ 语音条；支持扫码登录 B 站账号。

~~可以让群友直接在群里听司冯音乐。~~

## 功能

| 指令 | 权限 | 行为 |
| --- | --- | --- |
| `/提取音频 BV号` | 所有人 | 提取音频，默认整段发送一条 QQ 语音，源视频上限 100MB |
| `/账号登录` | 管理员 | 发送 B 站登录二维码，扫码后自动写入配置 |
| `/账号状态` | 管理员 | 查看当前配置的 B 站账号并校验 Cookie |
| `/退出登录` | 管理员 | 清除配置里的 B 站 Cookie |

## 使用方法

1. 在 B 站视频页复制 BV 号，例如 `BV1ikYa6zEkp`；
2. 发送 `/提取音频 BV1ikYa6zEkp`；
3. 机器人先回复视频标题，然后发送语音。

插件只接受 BV 号。分 P 视频默认提取 P1。

## 扫码登录

插件加载后不需要手动找 Cookie：

1. AstrBot 管理员在私聊或群里发送 `/账号登录`；
2. 机器人发送二维码图片；
3. 用哔哩哔哩 App 扫码，并在手机上确认；
4. 机器人提示登录成功，Cookie 会写入插件配置的 `cookie` 项；
5. 后续 `/提取音频` 自动使用该账号。

> `/账号登录` 默认只允许 AstrBot 管理员触发，避免群友把自己的账号绑到机器人上。
> 如果私聊里也无法使用，请先在 AstrBot 配置里把自己的 QQ 设为管理员。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enable_slicing` | `false` | 是否开启语音切片；关闭时整段发送一条语音 |
| `audio_chunk_seconds` | `60` | 切片长度，仅在开启切片时生效 |
| `max_audio_chunks` | `30` | 单次最多发送多少段语音，仅在开启切片时生效 |
| `audio_send_interval` | `0.6` | 多段语音发送间隔（秒），仅在开启切片时生效 |
| `max_audio_mb` | `100` | B 站 360P 源文件体积上限，超过不下载 |
| `send_progress` | `true` | 是否先发送标题与“正在提取音频”的提示 |
| `cooldown_seconds` | `20` | 单用户冷却，0 表示关闭 |
| `max_concurrent` | `1` | 同时处理的任务数 |
| `timeout_seconds` | `60` | 接口请求超时；下载另有至少 120 秒，转码最多 60 秒 |
| `cookie` | 空 | B 站 Cookie，扫码登录时不用手动填 |
| `proxy` | 空 | 下载代理，如 `http://127.0.0.1:7890` |

## 注意事项

由于某些原因，目前只在 QQ 官方机器人（`qq_official`）上验证过；OneBot 未测试，可能发不出语音条。
